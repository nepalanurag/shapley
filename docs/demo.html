Shapley Characteristic Function & Axiomatic Foundation

Lloyd S. Shapley (1953) · Nobel Memorial Prize

Every coalition subset S ⊆ N receives an objective capability score v(S) ∈ [0, 100] scored based on four weighted criteria: Complexity, Impact, Originality, and Unblocking. Marginal contributions are evaluated as v(S ∪ {i}) − v(S).

φi =
S ⊆ N \ {i} ∑
|S|! · (n − |S| − 1)! n!
×
[ v(S ∪ {i}) − v(S) ]
1. Efficiency Σ φᵢ = 100% Total bounty distributed with 0 leakage.
2. Symmetry φᵢ = φⱼ if equal Equal marginal impact yields equal share.
3. Dummy Player φᵢ = 0 if no value Zero marginal utility yields zero bounty.
4. Monotonicity v(S ∪ {i}) ≥ v(S) Enforced against evaluation regressions.

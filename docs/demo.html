Shapley Characteristic Function & Axiomatic Foundation

Lloyd S. Shapley (1953) · Nobel Memorial Prize

Every coalition subset S ⊆ N receives an objective capability score v(S) ∈ [0, 100] scored by Gemini based on four weighted criteria: Complexity, Impact, Originality, and Unblocking. Marginal contributions are calculated as v(S ∪ {i}) − v(S).

φi =
S ⊆ N \ {i} ∑
|S|! · (n − |S| − 1)! n!
×
v(S ∪ {i}) − v(S)
1. Efficiency Σ φᵢ = 100% Total bounty distributed with 0 leakage.
2. Symmetry φᵢ = φⱼ if equal Equal marginal impact yields equal share.
3. Dummy Player φᵢ = 0 if no value Zero marginal utility yields zero bounty.
4. Monotonicity v(S ∪ {i}) ≥ v(S) Strictly enforced against LLM regressions.

System Architecture & Workflows

Dual-track operational pipelines for Maintainers and Autonomous Agent Swarms

How It Works in 4 Steps (No Math Degree Required)

From raw GitHub commit activity to fair, automated payouts in developers' digital wallets:

1. Connect & Clean We inspect the real code changes, stripping out whitespace and auto-linter noise.
2. Simulate Teams We evaluate what happens with and without each teammate on the project.
3. Calculate Fair Share Cooperative game theory determines everyone's true contribution down to the penny.
4. 1-Click Payout Maintainer reviews and clicks once to disburse funds directly via PayPal REST API.

Pipeline A: Open Source Maintainer Attribution & PayPal Settlement

01 / Ingestion

AST & Diff Quarantine

Extracts commits, parses diffs, isolates comments from executable code, and verifies GPG signatures.

02 / Evaluation

Hybrid Scorer

Blends 30% AST physical signals (tests, cyclomatic branches) with 70% Gemini semantic capability scoring.

03 / Proofs

Axiomatic Audit

Computes Shapley values, guarantees exact-penny conservation (Hare-Niemeyer), and builds Merkle tree.

04 / Disbursal

PayPal Payouts REST

Submits signed idempotent batch transfer via PayPal Payouts API. Zero penny rounding leakage.

Pipeline B: Autonomous Agent Swarm & MCP Protocol

Layer 1 / Autonomous Orchestration

Multi-Agent Swarm

Specialized agents collaborate on tasks (Architect, Security Auditor, Test Engineer, Doc Writer).

Layer 2 / Marginal Pricing

Shapley Pricing Engine

Each agent's contribution is priced according to marginal capability increase, preventing freeloader exploitation.

Layer 3 / Machine Settlement

Programmatic Payouts

Agents receive micro-disbursals to authenticated PayPal digital wallets upon successful release execution.

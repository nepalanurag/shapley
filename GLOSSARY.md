# Shapley Protocol

Algorithmic revenue settlement infrastructure that uses cooperative game theory to distribute shared grant pools to open-source contributors with exact-penny conservation.

## Attribution

**Coalition**:
A specific subset of contributors drawn from the total participant set whose joint output is evaluated as a team.
_Avoid_: Group, sub-team, squad, cluster

**Valuation**:
The real-valued utility $v(S) \in [0, 100]$ generated by a coalition subset, representing its collective semantic code impact under boundary condition $v(\emptyset) = 0$.
_Avoid_: Score, rating, grade, points, karma

**Marginal Contribution**:
The difference in collective valuation when a specific contributor joins an existing coalition.
_Avoid_: Delta, incremental value, individual score, diff points

**Shapley Value**:
The unique mathematically fair fractional share awarded to a contributor, averaged over all possible coalition permutations according to game-theoretic axioms.
_Avoid_: Split, cut, percentage, dividend, tip

## Treasury & Escrow

**Grant Pool**:
The total monetary amount in fiat currency committed by a sponsor to fund a specific repository milestone or project release.
_Avoid_: Pot, bounty, prize, purse, reward pool

**Authorization Hold**:
A 29-day non-custodial pre-authorization placed on a sponsor's funding source via PayPal Orders v2 that locks funds without transferring them to an intermediary.
_Avoid_: Escrow deposit, locked balance, escrow capture, reserve

**Solvency Proof**:
A cryptographically verifiable certificate confirming that required grant funds are actively held in a valid PayPal authorization state before work begins.
_Avoid_: Escrow receipt, solvency token, proof of funds

## Settlement & Accounting

**Apportionment**:
The deterministic largest-remainder algorithm (Hare-Niemeyer) that maps continuous fractional Shapley shares into integer cents, guaranteeing exact fund conservation.
_Avoid_: Rounding, truncation, penny adjustment, dust cleanup

**Batch Disbursement**:
The single atomic PayPal Payouts transaction that delivers exact-penny allocations directly to all contributor wallets simultaneously.
_Avoid_: Payout run, mass pay, distribution, wire transfer

**Merkle Audit Receipt**:
An RFC 6962 cryptographic proof binding an analysis run's commit diffs, coalition valuations, and final payouts to an immutable root hash.
_Avoid_: Transaction receipt, hash proof, audit log entry

**Contributor Claim**:
The cryptographic binding of a verified GitHub author identity to a designated PayPal recipient email address and IRS tax self-certification.
_Avoid_: Registration, wallet link, profile signup
